核心功能Core features

即時、離線、講者、摘要，會議全流程都覆蓋。Live, offline, speakers and summaries: the whole meeting workflow.

即時語音轉錄翻譯Live transcription & translation

擷取系統音訊，地端 AI 即時辨識並翻譯成繁體中文字幕顯示於終端機。開會、看影片、聽 Podcast 即時翻譯。Captures system audio and transcribes & translates it to subtitles in real time: meetings, videos, podcasts.

離線音訊檔批次處理Offline batch processing

支援 mp3 / wav / m4a / flac，使用 faster-whisper 離線轉錄翻譯，適合會後補做逐字稿。可選用 Qwen3-ASR（實驗）：中文會議字錯率 28.78% → 15.75%，中英夾雜更準；GPU 伺服器（v2.23.0）或本機（v2.24.0 起，Apple Silicon 用 MLX）都能跑。mp3 / wav / m4a / flac via faster-whisper, perfect for post-meeting transcripts. Optional Qwen3-ASR (experimental): Chinese meeting CER 28.78% → 15.75%, much better on code-switching. Runs on a GPU server (v2.23.0) or locally (v2.24.0+, MLX on Apple Silicon).

講者辨識Speaker diarization

自動辨識音訊中的不同講者並以不同顏色標示，支援自動偵測或手動指定講者人數。Detects different speakers and color-codes them; auto-detect or set the speaker count manually.

AI 會議摘要AI meeting summary

地端 LLM 整理出重點摘要、決議、待辦、風險與議題，每一條都附逐字稿的時間點，引用經過比對，另附校正逐字稿。A local LLM extracts key points, decisions, action items, risks and topics (each citing the transcript timestamp, with citations checked), plus a corrected transcript.

時間軸互動逐字稿Interactive transcript

HTML 逐字稿內嵌音訊播放器與波形圖，點波形即跳到該時間點，播放時對應段落即時高亮。HTML transcript with an embedded player and waveform: click to seek; the current line highlights as it plays.

接進你的系統Integrates with your systems

可當成語音後端，已接上 jt-doc-tools 與 jt-vc-portal：上傳錄音或會議錄影 → 辨識、分離講者、校正 → 產出會議摘要與決議，每一條都指得回誰在第幾分鐘說的。全程在自己的機器上跑。Use it as a speech backend: already wired into jt-doc-tools and jt-vc-portal: upload a recording or meeting video → transcribe, separate speakers, correct → summaries and decisions, each citing who said it and when. All on your own hardware.

伺服器模式Server mode

./install.sh --server 裝在無桌面的主機上，WebUI 以 systemd 服務常駐、開機自動啟動，區網其他電腦用瀏覽器就能操作。可限制來源網段、加上 TLS。./install.sh --server installs on a headless box; the Web UI runs as a systemd service on boot and anyone on the LAN can drive it from a browser. Source ranges and TLS are configurable.

雙向字幕 + 16 種模式Bidirectional & 16 modes

英中 / 日中 / 韓中雙向，同時擷取系統音訊與麥克風，對方外語翻中文、自己中文翻外語；另支援台語（台灣閩南語）辨識，共 16 種功能模式。EN↔ZH / JA↔ZH / KO↔ZH bidirectional from system audio + mic, plus Taiwanese Hokkien ASR; 16 modes in total.

台灣華語朗讀Taiwanese Mandarin TTS

把文字、講稿、摘要念出來，邊念邊顯示字幕，也能存成 MP3（v2.27.0）。模型 VoxCPM2 支援中、英、日、韓等 30 種語言，目前朗讀針對台灣華語調校（夾雜英文也行），雙向口譯也用它念英文。在自己的 GPU 伺服器或 Apple Silicon Mac 合成（Windows＋NVIDIA 顯示卡可選用本機合成，beta），可用內建 AI 聲音或匯入取得同意的錄音；也可選台灣口音的 BreezyVoice（較慢）。Read text, scripts and summaries aloud with live subtitles, or save MP3 (v2.27.0). The VoxCPM2 model supports 30 languages, including Chinese, English, Japanese and Korean; read-aloud is tuned for Taiwanese Mandarin (mixed-in English works) and interpretation uses it to speak English. Runs on your GPU server or Apple Silicon Mac (Windows with an NVIDIA GPU can opt into local synthesis, beta) with built-in AI voices or a consented voice you import; BreezyVoice offers a native Taiwanese accent (slower).

雙向語音口譯Two-way voice interpretation

英中線上會議：對方說的英文翻成中文念給你聽、你說的中文翻成英文經虛擬麥克風念給對方聽（v2.28.0）。邊合成邊播，第一段約 0.3～0.7 秒出聲；自己念的聲音被錄回去會自動略過，不會翻來翻去。English-Chinese online meetings: what they say in English is read to you in Chinese, and what you say in Chinese is read to them in English through a virtual microphone (v2.28.0). Streaming synthesis starts in about 0.3-0.7 s, and your own playback picked up again is dropped so nothing loops.

三種部署方式Three ways to deploy

一台電腦就能跑；要更快，再加一台 GPU 伺服器；要給整個團隊用，架成伺服器。Run on one machine, add a GPU server for speed, or host it as a server for your whole team.

單機模式Single machine

一台 Mac、Windows PC 或 Linux 桌機即可完成所有處理，不需要額外硬體。One Mac, Windows PC or Linux desktop handles everything, no extra hardware.

  • macOS Apple Silicon（M1–M4）：mlx-whisper Metal GPU 加速，辨識約 1–3 秒macOS Apple Silicon (M1–M4): mlx-whisper Metal GPU, ~1–3 s recognition
  • Windows + NVIDIA GPU：安裝程式自動啟用 CUDA，辨識約 0.5–1 秒Windows + NVIDIA GPU: installer auto-enables CUDA, ~0.5–1 s
  • Linux：PipeWire / PulseAudio 直接擷取系統音訊，免裝虛擬音效卡；有 NVIDIA GPU 時自動走 CUDALinux: captures system audio via PipeWire / PulseAudio with no virtual sound card; uses CUDA when an NVIDIA GPU is present
  • 無 GPU / Intel Mac：CPU 辨識，搭配 small 模型可用No GPU / Intel Mac: CPU recognition with the small model

本機 + GPU 伺服器Client + GPU server

本機負責音訊擷取與介面，辨識與講者辨識交給區網內的 GPU 伺服器（系統音訊與麥克風兩路都可送遠端）。The client captures audio & UI; recognition and diarization run on a LAN GPU server (both system audio & mic).

  • 離線辨識快 5–10 倍，即時辨識約 0.3–0.5 秒Offline 5–10× faster; live recognition ~0.3–0.5 s
  • 伺服器可為 DGX Spark 或裝有 NVIDIA GPU 的 Linux 主機（RTX 4090 / 5090 亦可）DGX Spark or any Linux box with an NVIDIA GPU (RTX 4090 / 5090 work too)
  • 伺服器離線自動降級為本機處理，不中斷使用Auto-falls back to local if the server is offline, no interruption

伺服器模式Server mode

裝在無桌面的 Linux 主機（install.sh --server），WebUI 常駐，區網內的電腦用瀏覽器上傳錄音處理（遠端操作需要管理密碼）。Install on a headless Linux host (install.sh --server): the Web UI runs as a service; computers on your LAN upload recordings from the browser (remote use needs the admin password).

  • 搭配 GPU 伺服器（建議）：2 vCPU、4 GB 記憶體、30 GB 磁碟即可，辨識與講者辨識都在 GPU 伺服器上（實測 37 分鐘會議，記憶體峰值約 0.4 GB）With a GPU server (recommended): 2 vCPU, 4 GB RAM, 30 GB disk is enough; recognition and diarization run on the GPU server (measured: 37-min meeting peaks at ~0.4 GB RAM)
  • 不搭配 GPU 伺服器：改在 CPU 上辨識，建議 8 核、8 GB 以上；長錄音要花數倍於錄音長度的時間Without a GPU server: CPU recognition; 8 cores and 8 GB+ RAM recommended; long recordings take several times their length
  • 已與 jt-doc-tools、jt-vc-portal 串接Already integrated with jt-doc-tools and jt-vc-portal

自動辨識音訊中的不同講者，以不同顏色清楚標示，支援自動偵測或手動指定 2–20 位講者。誰在什麼時候說了什麼，一目了然。Identifies different speakers and color-codes them; auto-detect or set 2–20 speakers manually. Who said what, when, at a glance.

AI 會議摘要AI meeting summary

重點摘要、事件與影響、決議、待辦（負責人、期限）、風險、未決問題、議題時間軸、發言統計。每一條都附逐字稿的時間點，而且會比對引用的原文是不是真的講到這件事；點時間點就跳到依據的那段原文。分析與 jt-doc-tools 的會議摘要是同一套。Key points, events & impacts, decisions, action items (owner, due), risks, open questions, a topic timeline and speaker statistics. Every item cites a transcript timestamp, and each citation is checked against what was actually said; click a timestamp to jump to the source. Same analysis as the jt-doc-tools meeting summary.

線上會議雙向語音口譯Two-way voice interpretation in online meetings

英中雙向會議裡把譯文念出來：對方說的英文翻成中文念到你的耳機，你說的中文翻成英文、用合成語音送進會議。只有你的電腦要裝，對方照常開會、什麼都不用裝。下圖是 Mac（Bianca，說英文）與 Windows（Kevin，說中文）兩台電腦用 Jitsi Meet 實際開會的畫面；原理上任何線上會議軟體都能用（Zoom、Microsoft Teams、Google Meet…）：jt-live-whisper 聽的是電腦播出的會議聲音、說的話經麥克風送進會議，不需要會議軟體配合；目前實際開會測過的是 Jitsi Meet。In English-Chinese meetings the translations are spoken: the other side's English is read to you in Chinese in your headset, and your Chinese is sent into the meeting in English with a synthesized voice. Any online meeting app should work (Zoom, Microsoft Teams, Google Meet…): jt-live-whisper listens to the meeting audio your computer plays and speaks through a microphone, so the meeting app needs no integration; so far it has been tested in real meetings on Jitsi Meet.
