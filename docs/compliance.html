資料保護與合規Data protection & compliance

資料可以不出去Your data can stay in

語音、逐字稿、翻譯、摘要都可以完全在你自己的設備上處理，不需要任何雲端 AI 服務，能幫助組織落實個人資料保護、資訊安全與 AI 管理的要求。Speech, transcripts, translations and summaries can be processed entirely on your own hardware with no cloud AI service, which helps organizations meet privacy, security and AI governance requirements.

個資法、GDPR 是法律，規範組織實際怎麼處理個人資料；ISO/IEC 27001:2022、ISO/IEC 42001:2023 是管理制度標準，驗證組織在指定範圍內的管理制度。兩者都不是針對某一套軟體，所以本工具箱不宣稱「通過」或「符合」任何法規或認證，用了它也不代表某個部署就合法或取得驗證。這一頁說明工具本身做到什麼（多半只是控制措施的一部分或佐證），以及你的組織使用後還要做哪些事。本頁不是法律意見，也不是程式的安全稽核報告。Privacy laws such as Taiwan's PDPA and the GDPR govern how an organization actually handles personal data; ISO/IEC 27001:2022 and ISO/IEC 42001:2023 are management system standards that certify an organization's management system within a defined scope. Neither applies to a piece of software, so the toolbox claims no certification, and using it does not make a deployment lawful or certified. This page explains what the tool does (mostly part of a control, or supporting evidence) and what your organization still needs to do. It is neither legal advice nor a security audit of the code.

資料在哪裡Where your data lives

錄音、逐字稿、摘要可以完全在你的內網裡處理與保存；雲端 AI 服務完全用不到。實際資料流向依你的部署與設定決定。Recordings, transcripts and summaries can be processed and stored entirely inside your network; no cloud AI service is involved. Actual data flows depend on your deployment and settings.

資料Data在哪裡處理、存在哪裡Where it is processed and stored
會議錄音、即時音訊Meeting recordings, live audio你的電腦；選用 GPU 伺服器時送到你自己架設的 GPU 伺服器辨識，暫存音檔辨識完就刪（處理出錯也會刪；伺服器當機時可能留在系統的暫存資料夾，由作業系統清理）Your computer; with a GPU server, audio goes to your own server for recognition and the temporary file is deleted afterwards (also on errors; if the server crashes it may remain in the system temp folder until the OS cleans it up)
逐字稿、翻譯、摘要Transcripts, translations, summaries你的電腦（logs/）；翻譯與摘要送到你自己設定的 LLM 伺服器（例如內網的 Ollama）Your computer (logs/); translation and summaries use the LLM server you configure (e.g. Ollama on your LAN)
錄音檔Audio files你的電腦（recordings/）Your computer (recordings/)
朗讀用的參考錄音（聲音）Reference recordings for text-to-speech (voices)你的電腦（tts_voices/）；用 GPU 伺服器合成時伺服器依內容快取一份。刪除聲音時本機那份立刻刪，GPU 伺服器那份一起刪；伺服器連不上時記在待刪清單，下次用 GPU 伺服器朗讀時補刪（在那之前伺服器上還有一份）Your computer (tts_voices/); the GPU server caches a copy by content. Deleting a voice removes the local copy at once and the server copy too; if the server is unreachable it goes on a pending list and is deleted the next time the GPU server is used for reading aloud (until then the server still has it)
設定（含密碼雜湊、轉發平台的認證）Settings (password hashes, forwarding credentials)你的電腦（config.json）Your computer (config.json)
  • 不需要 ChatGPT、Claude、Gemini 等雲端 API 金鑰，不會把內容送給第三方 AI 服務No ChatGPT, Claude or Gemini API keys; nothing is sent to third-party AI services
  • WebUI 網頁不載入外部的字型、腳本或追蹤程式The WebUI loads no outside fonts, scripts or trackers
  • 實際資料流向依你的部署與設定決定：自架的主機可能在別的國家、備份可能放到雲端、遠端連線與字幕轉發會把內容送到別處；有沒有跨境傳輸要看這些Actual data flows depend on your deployment and settings: a self-hosted server may be abroad, backups may go to a cloud, remote access and forwarding send content elsewhere; whether data crosses borders depends on these

工具本身做到的What the tool does

存取控制Access control

  • WebUI：管理密碼與唯讀密碼（設定檔只存雜湊）、限制哪些 IP 可以連、加密連線（TLS，預設關閉）WebUI: admin and read-only passwords (only hashes stored), IP allow-list, TLS (off by default)
  • 安全設定、轉發、關鍵字通知、懸浮字幕這幾頁只有在本機才能打開Security, forwarding, keyword alert and overlay settings open only on the local machine
  • 反向代理後面一定要設 webui.trusted_proxies：只採信這些代理轉來的來源位址，偽造的不算。沒設定時（v2.31.1 起），同一台代理轉來、帶著轉送標頭的請求一律當成遠端（要密碼、僅限本機的頁面不開）；代理完全不加轉送標頭時分不出來，仍會被當成本機Behind a reverse proxy, always set webui.trusted_proxies: only forwarded addresses from those proxies are believed, forged ones are not. Without it (since v2.31.1), requests from a proxy on the same machine that carry forwarding headers are treated as remote (password required, local-only pages refused); a proxy that adds no forwarding headers cannot be detected and still counts as local
  • GPU 伺服器的連線是 HTTP、沒有加密，LLM 伺服器預設也是 HTTP（v2.31.4 起可用 https）：放在可信任的內網或 VPN；LLM 伺服器的 API 金鑰以明文存在 config.json，請限制檔案權限The GPU server connection is plain HTTP and the LLM server's is HTTP by default (https since v2.31.4): keep them on a trusted LAN or VPN; the LLM server API key is stored in plain text in config.json, so restrict that file's permissions
  • REST API：每個呼叫端一把金鑰（只存雜湊），每個呼叫端只看得到自己送的作業；從網址抓音檔時只允許設定好的主機REST API: one key per client (only hashes stored); each client sees only its own jobs; audio URLs limited to allowed hosts
  • 伺服器版的服務以安裝資料夾的擁有者身分執行，不會因為用 sudo 安裝就一律以 root 執行The server edition runs as the install folder's owner, not root just because sudo was used

可追溯、可人工覆核Traceable, reviewable

  • 會議摘要的決議、待辦、風險等每一條都附時間點與引用的原文，可以回到逐字稿查證Every decision, action item and risk in a meeting summary cites timestamps and the source text
  • 引用驗證不過的項目直接不輸出；整段摘要裡找不到依據的數字或名詞會標示出來Items whose citations do not check out are dropped; ungrounded numbers or names in the summary are flagged
  • 校正後的逐字稿保留原始辨識結果；校正幅度異常時自動保留原文Corrected transcripts keep the raw recognition; abnormal edits fall back to the original

透明與品質Transparency and quality

  • 原始碼公開（Apache-2.0），可以自行稽核Open source (Apache-2.0), auditable
  • 準確度、速度與已知限制公開在 BENCHMARKS.mdAccuracy, speed and known limits are published in BENCHMARKS.md
  • 每次發版前在三個平台跑守門測試（測試程式與結果沒有公開）；改了什麼都記在 CHANGELOGA release gate runs on three platforms before every release (tests and results not published); every change is in the CHANGELOG
  • 已安裝的模型與套件不會自己更新：朗讀模型、辭典資料、Windows 口譯麥克風驅動固定版本；辨識、講者辨識、翻譯模型與 Python 套件是安裝時取得當時的版本，沒有全部鎖定Installed models and packages never update themselves: text-to-speech models, dictionary data and the Windows interpreter mic driver are pinned; recognition, diarization and translation models and Python packages are whatever was current at install time, not all pinned

朗讀與保存期限Text-to-speech and retention

  • 內建的 8 個中文聲音是 AI 依文字描述產生，不是真人錄音；匯入自己的聲音要勾選「已取得錄音者的書面同意」並填寫來源（使用規範：程式只記錄聲明，不檢查同意書）The 8 built-in Chinese voices are AI-generated from text descriptions, not recordings of real people; importing your own requires confirming the speaker's written consent and recording its source (a usage rule: the program records the statement but does not check the consent form)
  • 錄音者要求刪除時，刪除聲音會刪掉本機那份與 GPU 伺服器的快取（伺服器連不上時下次朗讀補刪）；已合成的語音檔與備份要另外處理When a speaker asks for deletion, deleting the voice removes the local copy and the GPU server's cache (if unreachable, at the next reading); synthesized audio files and backups must be handled separately
  • 雙向語音口譯念給對方聽的英文是 AI 合成：第一次念之前預設先說明這是 AI 口譯Two-way interpretation speaks AI-synthesized English to the other side, and by default first tells them it is an AI interpreter
  • REST API：確認收到（ACK）後刪除作業內容；沒有確認的保留 7 天REST API: job content is deleted after acknowledgement; unacknowledged jobs are kept 7 days
  • REST API 日誌記錄每個請求（含授權失敗）與作業步驟，不記錄金鑰、授權標頭、詞彙庫與逐字稿內容；WebUI 登入失敗、設定變更、金鑰新增與撤銷目前沒有記錄REST API logs record every request (including authorization failures) and job steps, never keys, authorization headers, glossaries or transcript text; WebUI login failures, settings changes and key creation or revocation are not logged yet
  • 「刪除」都是一般刪除檔案，不是不可復原的抹除；備份、快照、已下載或轉寄的副本不會跟著刪Deletion means ordinary file deletion, not secure erasure; backups, snapshots and copies already downloaded or forwarded are not affected

你的組織使用後要做的What your organization does

錄音前Before recording

  • 告知：個資法第 8 條要告知蒐集者名稱、目的、資料類別、利用的期間、地區、對象及方式、當事人的權利與行使方式、不提供的影響；GDPR 見第 13、14 條Notice: Taiwan's PDPA Article 8 requires the collector's name, purpose, data categories, period, area, recipients and manner of use, data-subject rights and how to exercise them, and the effect of not providing data; for the GDPR see Articles 13 and 14
  • 合法依據：同意只是其中一種（個資法第 19 條、GDPR 第 6 條），選定並留下紀錄；用同意的話要能證明、可以撤回Legal grounds: consent is only one option (PDPA Article 19, GDPR Article 6); choose one and keep records; consent must be provable and withdrawable
  • 特殊的資料：講者辨識會計算聲紋特徵來區分講者（不比對身分）、聲音複製會保存某個人的聲音，在你適用的法規下算不算特種／敏感資料要評估Special data: diarization computes voice features to tell speakers apart (no identity matching) and voice cloning stores a person's voice; assess whether these count as special or sensitive data under your laws
  • 用途限制：決定哪些會議可以錄（人事、法務、醫療要另外考慮）；只錄需要的，可以只即時轉錄、不存錄音Purpose limits: decide which meetings may be recorded; record only what you need, or transcribe live without keeping audio

部署與存取Deployment and access

  • 一定要設密碼：WebUI 開在所有網路介面上，沒設密碼又沒限制來源時，同網段的人連得進來；設管理與唯讀密碼、限制 IP，同網段也建議開 TLS；放在反向代理後面時設定 trusted_proxies，並讓代理送出 X-Forwarded-ForAlways set passwords: the WebUI listens on all interfaces; set admin and read-only passwords, restrict IPs, use TLS even on the same network, and behind a reverse proxy set trusted_proxies and have the proxy send X-Forwarded-For
  • GPU 伺服器與 LLM 伺服器放在內網：GPU 伺服器的連線沒有加密、LLM 伺服器預設也沒有（可改用 https）；用防火牆只開給需要的電腦，跨網段走 VPNKeep the GPU and LLM servers internal: the GPU server connection is not encrypted and the LLM server's is not by default (https is possible); firewall them to the machines that need them and use a VPN across networks
  • 模型授權：確認選用的模型授權符合你的用途，特別是 NLLB 600M 僅限非商業用途Model licenses: check the licenses fit your use, especially NLLB 600M, which is non-commercial only
  • 主機安全：系統更新、帳號管理、磁碟加密（FileVault、BitLocker、LUKS）Host security: updates, account management, disk encryption (FileVault, BitLocker, LUKS)

保存與刪除Retention and deletion

  • 訂出保存期限：依規範定期清理 recordings/、logs/（包含備份）Set retention: clean up recordings/ and logs/ on schedule, backups included
  • 刪除要求：錄音、逐字稿、摘要、聲音、已合成的語音檔、備份與快照、已下載或轉寄的副本都要處理；需要不可復原的抹除時用磁碟加密與媒體報廢程序Erasure requests: cover recordings, transcripts, summaries, voices, synthesized audio, backups and snapshots, and copies already downloaded or forwarded; use disk encryption and media disposal where secure erasure is needed
  • 備份：需要保存的自行備份，定期測試還原Backups: back up what you keep and test restores

人工覆核與外部服務Human review and outside services

  • AI 輸出要人確認：可能聽錯、誤譯、漏掉或寫錯決議與待辦對象；用在對外、決策、法律、醫療、財務前請對照原文Review AI output: it can mishear, mistranslate or get decisions and owners wrong; check against the source before external, legal, medical or financial use
  • 合成語音：對外使用時標示為 AI 合成；同意書寫清楚用途、範圍、期限、撤回與刪除；不可冒充本人Synthetic speech: label it as AI-generated; consent should cover purpose, scope, duration, withdrawal and deletion; never impersonate
  • 字幕轉發、外部 LLM 或 GPU 伺服器：開啟前評估那個服務的資料保存與使用政策Forwarding, outside LLM or GPU servers: assess their data retention and use policies first
